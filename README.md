# Frossard Consultoria

Site estático da Frossard Consultoria preparado para GitHub Pages.

## Publicação

1. Crie um repositório público no GitHub.
2. Envie `index.html`, `.nojekyll` e `CNAME` para a raiz do repositório.
3. Em Settings > Pages, selecione **Deploy from a branch**.
4. Selecione a branch `main` e a pasta `/(root)`.
5. Salve e aguarde a publicação.

Domínio configurado no arquivo CNAME:
https://frossardconsultoria.com.br
